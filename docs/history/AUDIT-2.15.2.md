# longBlog iOS 2.15.2 · build 50

## 范围

基于远端 main `8ec28bd`（2.15.1 build 49）新建 `fix/editor-dirty-instant-memo-and-revert-20261113`。只修改原生 iOS 项目和测试，未操作真实文章/草稿/说说、未调用真实业务写接口。整体配色、玻璃卡片、导航和编辑工具栏保持原样。

## 1. 撤销所有未提交操作

- 文章列表存在待提交变更时，在「保存预览」旁显示原生 `arrow.uturn.backward` 按钮，辅助功能名称为「撤销所有未提交操作」。无变更时隐藏；同步或文章任务期间禁用，防止互相覆盖。
- 操作前确认，说明恢复范围、尚未发布的新草稿保留、云端已提交操作不会撤回、保留本地备份。
- 确认前冻结完整暂存选择及不透明 `revertGuard`；确认后再次核验文章、已跟踪附件、侧件、同步状态、目录和仓库。确认期间变动则拒绝。
- 已跟踪文章恢复已确认的 Git blob；如当前字节不同，通过只读 GET 获取并校验不可变 blob，再核对远端 HEAD。远端已改动/删除、未认领同名路径、pending 或未完成迁移/撤销日志，均保守拒绝。
- 新草稿只取消 publish，保留正文、附件、未知元数据、注释、CRLF 和正文原字节；不能安全识别发布字段时不改写。
- 同一 articleTask 互斥，短暂安装门禁防止应用内保存交错；目录重新归类使用已有安全归档工具，在后台执行。未改变的附件不 base64 备份或重写，但最终完整性校验仍需读取。
- 写入前保留 `.longblog-revert-<UUID>.json`，含 before/after、状态和布局信息。失败/中断保留 prepared 日志，不静默重放；目录迁移另保留已有 `.longblog-backups`。
- 撤销没有云端 commit、push、ref 写入。多文件不是跨文件系统原子事务；中途失败可能需要凭日志人工恢复，未声称跨进程 File Provider 竞态完全消除。

## 2. 只认实际内容变化

文章编辑器原来的选区回调并没有直接设置 dirty；真正问题是不可逆的修改锁存、无变化保存重写，以及恢复草稿只看有附件元数据就提示。

- 文章比较标题、正文、摘要、发布状态和正文实际引用的本地新增附件内容；说说比较正文、可见性、资源 ID 和未上传附件。
- 光标移动、选择、键盘、展开摘要、预览不进入内容基线。编辑后恢复原文、可见性改回、移除新增附件后恢复原状态，重新视为干净。
- 文章/说说取消与交互式下滑退出共享比较；现有内容无变化点保存直接关闭，不改 updatedAt、不生成保存成功通知、不触发发布/PATCH。
- 说说结束编辑、预览、后台不再无条件写草稿；真正内容变更仍防抖保存。导入中/失败/缺失附件及未知写入结果保持谨慎处理。
- 草稿写入、删除、附件恢复副本使用原有串行队列，防止 Undo/Redo 或清理后再插入附件的先后竞态。只清理本会话生成/明确接受的无差异恢复副本；未接受的历史恢复不擅自删除。
- 同文附件恢复只读核验实际字节，避免相同附件元数据反复提示；说说恢复仍以草稿自己的旧 originalSnapshot 为冲突基线，不把旧草稿冒充新远端版本。

## 3. 说说详情先显示本地全文

根因：原 `rebuild` 被 `_visible` 阻断，而 `_visible` 到 `viewDidAppear` 才打开；随后还要同步准备 WebKit 脚本、等待 ready/JS/rAF 高度。

- 进入详情时先选当前账号缓存记录并构建视图，不等页面转场结束或网络。
- 冷 WebKit 期间先同步显示完整、不截断的本地 Markdown 原文；大型 bundled scripts 改后台读取，回主线程安装隔离 WebKit。
- 生产 JS 同步汇报首个高度（仍保留 rAF/字体/图表/ResizeObserver 后续测量），避免隐藏 WebKit 的动画帧暂停阻断接力。
- 收到经 nonce/revision/source 核验的有效 DOM 高度后，先设置高度，再无动画隐藏并清空原生全文、显示完整格式化内容；不同时展示双份正文。
- Markdown、KaTeX、Mermaid 和安全过滤完整保留。排版资源失败/进程终止时仍显示本地全文。
- 账号/generation 变化会清理原生文本、DOM、媒体和过期回调；页面可见性继续控制媒体播放、下载和预览，不提前放开。
- 不承诺图片/附件在未缓存时零下载；冷启动全文到格式化内容的视觉接力、真实 WebKit 布局和辅助功能尚需真机验证。

## 4. 移除左下角小字

完全移除文章列表底部同步标签、活动指示器和 footer 占位。顶部同步文字、图标动画和失败反馈保留，不再上下重复显示。

## 真机验收

1. 光标、选区、键盘、预览后直接退出；修改后恢复原文退出；真实修改应保留草稿。
2. 文章/说说无变化轻点保存应关闭但不生成 updatedAt 或“已修改”。测试输入法组合文本、交互下滑和附件 Undo/Redo。
3. 首次/重复进入长说说、离线进入、只附件说说；检查原生全文到格式化内容切换和旧账号不泄露。
4. 暂存发布/下架/更新后点击撤销并确认；新草稿保留；远端变动/未确认提交时应拒绝而非覆盖。注意实际确认会改变本地文件，建议先用测试文章验收。
5. 文章滚到底部无同步小字，顶部状态依旧可读。
